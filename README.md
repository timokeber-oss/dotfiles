# dotfiles

Personal shell / git / tmux / herdr / pi / gh config.

```sh
git clone https://github.com/timokeber-oss/dotfiles ~/dotfiles
~/dotfiles/install.sh
```

Files in `home/` are symlinked into `$HOME`. Secrets and machine-specific
settings go in untracked `~/.zshrc.local` and `~/.gitconfig.local`.
